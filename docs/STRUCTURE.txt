MAIN MENU OPTIONS:

1. Concatenate OCR text files by date
2. Extract TRAVERSING ENTRANCES
3. Extract CABOTAGE ENTRIES
4. Extract BOTH (Traversing + Cabotage)
5. Extract by YEAR (Professional - 4 files per year)
6. Check missing files to process
7. Show database statistics
8. Export data (year/month/day/port/ship/captain)
9. Analyze data (year/port/ship/captain)
10. Database utilities (backup/reset/optimize)
0. Exit

WORKFLOW:

1. Extract data (Option 5)
   → Data saved to .data/extraction.db

2. Check progress (Option 6)
   → See what files are missing

3. Analyze data (Option 9)
   → Generate reports and statistics

4. Export data (Option 8)
   → Generate JSON and CSV files

5. Manage database (Option 10)
   → Backup, optimize, clean data

KEY FILES:

- main.py: Entry point, all menu options
- utils/extractor.py: Core extraction logic
- utils/db/database.py: SQLite database schema
- utils/export_data.py: Export to JSON/CSV
- utils/analyze_data.py: Generate reports
- utils/db/db_utils.py: Database management
- utils/db/check_missing.py: Track progress

RUNNING:

source .env && source .venv/bin/activate && python3 main.py

Or use quickstart script:
./quickstart.sh
