# Σύστημα Εξαγωγής Θαλάσσιων Δεδομένων Κούβας

Επαγγελματικό σύστημα εξαγωγής δεδομένων βασισμένο σε OCR για ιστορικές εφημερίδες (1850-1915) από το Diario de la Marina.

## 🌍 Γλώσσες Τεκμηρίωσης

- 🇬🇧 **English** - [README.md](../README.md)
- 🇪🇸 **Español** - [docs/README_ES.md](README_ES.md)
- 🇬🇷 **Ελληνικά** (τρέχον) - [docs/README_EL.md](README_EL.md)

---

## Χαρακτηριστικά

- **Εξαγωγή Δομημένων Δεδομένων**: Εξάγει καταχωρήσεις διαδρομών και καμπότατζ από έγγραφα OCR
- **Τροφοδοτούμενο από ΤΝ**: Χρησιμοποιεί OpenAI GPT-4o-mini για ευφυή ανάλυση κειμένου
- **Βάση Δεδομένων SQLite**: Μόνιμη αποθήκευση με αποδοτικές ερωτήσεις
- **Επεξεργασία Πολλαπλών Νημάτων**: 16 ταυτόχρονοι εργάτες για γρήγορη εξαγωγή
- **Ευέλικτη Εξαγωγή**: Μορφές JSON και CSV με φιλτράρισμα πεδίων
- **Οργάνωση ανά Έτος**: Επεξεργασία δεδομένων ανά έτος με δυνατότητα επανεπεξεργασίας

## Δομή Καταλόγου OCR Εισόδου

Αυτή είναι η **ακριβής δομή** που απαιτείται για να ανιχνεύσει και να επεξεργαστεί σωστά το σύστημα τα αρχεία:

### Ιεραρχία Καταλόγων

```
.data/Nuevo/
├── 1850/
│   ├── 01/
│   │   ├── 1850_01_01_HAB_DM_U_01_0_V_003-001.txt
│   │   ├── 1850_01_01_HAB_DM_U_01_0_C_003-001.txt
│   │   ├── 1850_01_02_HAB_DM_U_01_0_V_003-001.txt
│   │   └── ...
│   ├── 02/
│   │   ├── 1850_02_01_HAB_DM_U_01_0_V_003-001.txt
│   │   ├── 1850_02_01_HAB_DM_U_01_0_C_003-001.txt
│   │   └── ...
│   └── 12/
│       └── ...
├── 1852/
│   ├── 01/
│   │   ├── 1852_01_01_HAB_DM_U_01_0_V_003-001.txt
│   │   ├── 1852_01_01_HAB_DM_U_01_0_C_003-001.txt
│   │   └── ...
│   ├── 02/
│   └── ...
├── 1857/
├── 1860/
└── ... (άλλα έτη)
```

### Κανόνες Δομής Καταλόγου

**Κατάλογοι Ετών**
- Μορφή: `YYYY` (έτος 4 ψηφίων)
- Παραδείγματα: `1850`, `1852`, `1876`, `1914`
- Τοποθεσία: `.data/Nuevo/YYYY/`

**Κατάλογοι Μηνών**
- Μορφή: `MM` (μήνας 2 ψηφίων, με μηδέν στα αριστερά)
- Εύρος: `01` έως `12`
- Τοποθεσία: `.data/Nuevo/YYYY/MM/`
- Παραδείγματα: `01` (Ιανουάριος), `02` (Φεβρουάριος), `12` (Δεκέμβριος)

**Κατάλογοι Ημερών**
- ΔΕΝ ΧΡΗΣΙΜΟΠΟΙΟΥΝΤΑΙ - Τα αρχεία βρίσκονται απευθείας σε καταλόγους μηνών
- Τα αρχεία αναγνωρίζονται ανά ημερομηνία στο όνομα αρχείου, όχι δομή καταλόγου

### Σύμβαση Ονοματοδοσίας Αρχείων OCR

Όλα τα αρχεία OCR πρέπει να ακολουθούν αυτό το ακριβές μοτίβο ονόματος:

```
YYYY_MM_DD_HAB_DM_U_01_0_[ΤΥΠΟΣ]_NNN-NNN.txt
```

**Στοιχεία Ονόματος Αρχείου:**

| Στοιχείο | Μορφή | Παράδειγμα | Περιγραφή |
|---------|-------|-----------|-----------|
| Έτος | `YYYY` | `1852` | Έτος 4 ψηφίων |
| Μήνας | `MM` | `01` | Μήνας 2 ψηφίων (01-12) |
| Ημέρα | `DD` | `15` | Ημέρα 2 ψηφίων (01-31) |
| Τοποθεσία | `HAB` | `HAB` | Αβάνα (σταθερό) |
| Δημοσίευση | `DM` | `DM` | Diario de la Marina (σταθερό) |
| Έκδοση | `U` | `U` | Αναγνωριστικό έκδοσης (σταθερό) |
| Αριθμός | `01` | `01` | Αριθμός έκδοσης (σταθερό) |
| Σελίδα | `0` | `0` | Αριθμός σελίδας (σταθερό) |
| **ΤΥΠΟΣ** | `V` ή `C` | `V` | **ΚΡΙΣΙΜΟ: Καθορίζει τον τύπο καταχώρησης** |
| Ακολουθία | `NNN-NNN` | `003-001` | Αναγνωριστικό ακολουθίας |

### Ανίχνευση Τύπου Αρχείου

Το σύστημα ανιχνεύει τύπους καταχωρήσεων από το στοιχείο `ΤΥΠΟΣ` στο όνομα αρχείου:

**Καταχωρήσεις Διαδρομής (Διεθνείς Αφίξεις)**
- Όνομα αρχείου περιέχει: `_V_` (V = Viajes/Ταξίδια)
- Παράδειγμα: `1852_01_15_HAB_DM_U_01_0_V_003-001.txt`
- Εξάγει: Αφίξεις διεθνών πλοίων με πλήρες λεπτομέρειες ταξιδιού

**Καταχωρήσεις Καμποταζ (Εγχώριες Αφίξεις)**
- Όνομα αρχείου περιέχει: `_C_` (C = Cabotaje/Παράκτιο)
- Παράδειγμα: `1852_01_15_HAB_DM_U_01_0_C_003-001.txt`
- Εξάγει: Αφίξεις εγχώριων/περιφερειακών πλοίων

### Πλήρες Παράδειγμα

```
.data/Nuevo/1852/01/
├── 1852_01_01_HAB_DM_U_01_0_V_003-001.txt    ← Διαδρομή (V)
├── 1852_01_01_HAB_DM_U_01_0_C_003-001.txt    ← Καμποταζ (C)
├── 1852_01_02_HAB_DM_U_01_0_V_003-001.txt    ← Διαδρομή (V)
├── 1852_01_02_HAB_DM_U_01_0_C_003-001.txt    ← Καμποταζ (C)
├── 1852_01_03_HAB_DM_U_01_0_V_003-001.txt    ← Διαδρομή (V)
├── 1852_01_03_HAB_DM_U_01_0_C_003-001.txt    ← Καμποταζ (C)
└── ...
```

## Εγκατάσταση

1. Κλωνοποιήστε το αποθετήριο
2. Δημιουργήστε εικονικό περιβάλλον: `python3 -m venv .venv`

## Σχήμα Βάσης Δεδομένων

### Πίνακας traversing
- `id`: Πρωτεύον κλειδί
- `source_file`: Αναγνωριστικό αρχείου πηγής (YYYY_MM_DD)
- `publication_day`: Ημερομηνία δημοσίευσης (YYYY-MM-DD)
- `arrival_date`: Ημερομηνία άφιξης (YYYY-MM-DD)
- `arrival_date_calc`: Υπολογισμένη ημερομηνία άφιξης
- `travel_departure_port`: Λιμάνι αναχώρησης
- `ship_type`: Τύπος σκάφους
- `ship_flag`: Σημαία/εθνικότητα
- `ship_name`: Όνομα πλοίου
- `master_role`: Ρόλος καπετάνιου/πατρόνου
- `master_name`: Όνομα καπετάνιου/πατρόνου
- `cargo_list`: Πίνακας JSON αντικειμένων φορτίου
- `raw_text`: Αρχικό εξαγόμενο κείμενο
- `travel_duration_value`: Διάρκεια ταξιδιού (αριθμητικό)
- `travel_duration_unit`: Μονάδα διάρκειας (ημέρες/ώρες)
- `ship_tons_capacity`: Χωρητικότητα τονάζ πλοίου
- `ship_tons_unit`: Μονάδα τονάζ
- `crew_number`: Μέγεθος πληρώματος
- `passenger_account`: Αριθμός επιβατών
- `quarantine`: Κατάσταση καραντίνας
- `forced_arrival`: Δείκτης αναγκαστικής άφιξης
- `obs`: Παρατηρήσεις/σημειώσεις
- `parsed_text`: Αναλυμένη αναπαράσταση κειμένου

### Πίνακας cabotage
Ίδια δομή με τον πίνακα traversing

### Πίνακας processed_files
- `id`: Πρωτεύον κλειδί
- `file_path`: Διαδρομή επεξεργασμένου αρχείου
- `processed_at`: Χρονοσήμανση επεξεργασίας
- `traversing_count`: Εξαγόμενες καταχωρήσεις διαδρομής
- `cabotage_count`: Εξαγόμενες καταχωρήσεις καμποταζ

## Ρύθμιση

### Κλειδί API OpenAI
Αποθηκεύστε κρυπτογραφημένο στο `llm_service/openai_key.txt`:
```bash
export ADATROP_TERCES=το_κλειδι_κρυπτογραφησης_σας
```

### Διαδρομή Βάσης Δεδομένων
Προεπιλογή: `.data/extraction.db`
Τροποποιήστε στον κώδικα ή περάστε ως παράμετρο σε `ExtractionDB()`

### Αριθμός Νημάτων
Προεπιλογή: 16 εργάτες
Ρυθμιζόμενο κατά την εκτέλεση επιλογών εξαγωγής

## Απόδοση

- **Ταχύτητα Επεξεργασίας**: ~100-200 καταχωρήσεις ανά λεπτό (εξαρτάται από API LLM)
- **Μέγεθος Βάσης Δεδομένων**: ~500MB για 60,000+ καταχωρήσεις
- **Χρήση Μνήμης**: ~2GB με 16 ταυτόχρονα νήματα
- **Χρήση Tokens**: ~0.5-1.0 tokens ανά καταχώρηση

## Χειρισμός Σφαλμάτων

- Ανεπεξέργαστο κείμενο OCR παραλείπεται
- Διπλές καταχωρήσεις αγνοούνται (περιορισμός UNIQUE)
- Αποτυχημένες κλήσεις API καταγράφονται
- Δημιουργούνται αντίγραφα ασφαλείας βάσης δεδομένων πριν από μεταναστεύσεις

## Αντιμετώπιση Προβλημάτων

### Δεν βρίσκονται αρχεία
- Επαληθεύστε ότι τα αρχεία OCR βρίσκονται στη δομή `.data/Nuevo/YYYY/`
- Ελέγξτε ονόματα αρχείων: `YYYY_MM_DD_*_V_*.txt` (διαδρομές) ή `*_C_*.txt` (καμποταζ)

### Σφάλματα βάσης δεδομένων
- Ελέγξτε δικαιώματα `.data/extraction.db`
- Επαληθεύστε ότι το SQLite είναι εγκατεστημένο
- Ελέγξτε αρχεία καταγραφής στο `.data/output/`

### Σφάλματα API
- Επαληθεύστε ότι το κλειδί API OpenAI έχει οριστεί
- Ελέγξτε υπόλοιπο tokens
- Ελέγξτε όρια ταχύτητας

## Ανάπτυξη

### Προσθήκη νέων τύπων εξαγωγής
1. Δημιουργήστε νέο προτρέπμα LLM στο `llm_service/llm_openai.py`
2. Προσθέστε μέθοδο εξαγωγής στο `utils/extractor.py`
3. Προσθέστε πίνακα βάσης δεδομένων στο `utils/db/database.py`
4. Προσθέστε επιλογή μενού στο `main.py`
