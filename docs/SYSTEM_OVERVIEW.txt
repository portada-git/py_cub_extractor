SISTEMA COMPLETO DE EXTRACCIÓN Y ANÁLISIS DE DATOS MARÍTIMOS
============================================================

COMPONENTES:

1. EXTRACTOR (extractor.py)
   - Procesa archivos OCR línea por línea
   - Identifica travesías (_V_) y cabotajes (_C_)
   - Usa IA (OpenAI) para extraer información estructurada
   - Almacena datos en SQLite automáticamente
   - Genera logs detallados
   - Rastreo de tokens usados

2. BASE DE DATOS (database.py)
   - SQLite con 3 tablas: traversing, cabotage, processed_files
   - Métodos para guardar y recuperar datos
   - Búsquedas por: año, mes, día, puerto, barco, capitán
   - Estadísticas y análisis
   - Evita duplicados automáticamente

3. EXPORTACIÓN (export_data.py)
   - Exporta datos a JSON y CSV
   - Múltiples opciones de filtrado:
     * Por año completo
     * Por mes específico
     * Por día específico
     * Por puerto
     * Por barco
     * Por capitán
   - Listados de puertos, barcos, capitanes únicos

4. ANÁLISIS (analyze_data.py)
   - Genera reportes detallados
   - Análisis por año, puerto, barco, capitán
   - Estadísticas de cargo
   - Contadores de frecuencia
   - Patrones comerciales

5. UTILIDADES (db_utils.py)
   - Gestión de base de datos
   - Backup y restore
   - Limpieza de datos
   - Optimización
   - Información de base de datos

FLUJO DE TRABAJO COMPLETO:

PASO 1: EXTRACCIÓN
   source .env && source .venv/bin/activate
   python3 main.py
   → Opción 5
   → Ingresar rutas y threads
   → Datos guardados en .data/extraction.db

PASO 2: VERIFICACIÓN
   python3 db_utils.py info
   → Ver estadísticas de la base de datos

PASO 3: ANÁLISIS
   python3 analyze_data.py year 1852
   → Ver análisis detallado del año

PASO 4: EXPORTACIÓN
   python3 export_data.py year 1852 .data/output
   → Generar archivos JSON y CSV

PASO 5: BÚSQUEDAS ESPECÍFICAS
   python3 export_data.py port 'Nueva York' .data/output
   python3 export_data.py ship 'Neptuno' .data/output
   python3 export_data.py master 'Cobos' .data/output

VENTAJAS DEL SISTEMA:

✓ Extrae una sola vez, reutiliza datos infinitamente
✓ No requiere reextracciones costosas
✓ Base de datos portable (SQLite)
✓ Búsquedas rápidas y flexibles
✓ Múltiples formatos de exportación
✓ Análisis y reportes automáticos
✓ Rastreo de archivos procesados
✓ Evita duplicados automáticamente
✓ Backup y restore fácil
✓ Logging completo

ARCHIVOS GENERADOS:

.data/extraction.db
   - Base de datos SQLite con todos los datos

.data/extraction_YYYYMMDD_HHMMSS.log
   - Log detallado de la extracción

.data/output/
   - Archivos JSON y CSV exportados
   - Reportes de análisis

EJEMPLOS DE USO:

# Ver estadísticas
python3 db_utils.py info

# Crear backup
python3 db_utils.py backup

# Analizar año 1852
python3 analyze_data.py year 1852

# Exportar año 1852
python3 export_data.py year 1852 .data/output

# Exportar mes de enero de 1852
python3 export_data.py month 1852 1 .data/output

# Exportar día 15 de enero de 1852
python3 export_data.py day 1852 1 15 .data/output

# Exportar datos del puerto Nueva York
python3 export_data.py port 'Nueva York' .data/output

# Exportar datos del barco Neptuno
python3 export_data.py ship 'Neptuno' .data/output

# Exportar datos del capitán Cobos
python3 export_data.py master 'Cobos' .data/output

# Listar todos los puertos
python3 export_data.py list-ports

# Listar todos los barcos
python3 export_data.py list-ships

# Listar todos los capitanes
python3 export_data.py list-masters

# Analizar puerto Nueva York
python3 analyze_data.py port 'Nueva York'

# Analizar barco Neptuno
python3 analyze_data.py ship 'Neptuno'

# Analizar capitán Cobos
python3 analyze_data.py master 'Cobos'

# Eliminar datos de año 1852
python3 db_utils.py delete-year 1852

# Eliminar duplicados
python3 db_utils.py delete-duplicates

# Optimizar base de datos
python3 db_utils.py vacuum

ESTRUCTURA DE DATOS:

Tabla: traversing
- id, source_file, publication_day, travel_duration
- travel_departure_port, ship_type, ship_name
- ship_tons_capacity, ship_tons_units
- master_role, master_name, cargo_list
- raw_text, departure_date, arrival_date
- extracted_at

Tabla: cabotage
- (misma estructura que traversing)

Tabla: processed_files
- id, file_path, processed_at
- traversing_count, cabotage_count

NOTAS IMPORTANTES:

1. La base de datos evita duplicados automáticamente
2. Los datos se guardan mientras se extrae (no al final)
3. Se puede pausar y reanudar la extracción
4. Los archivos ya procesados se rastrean
5. Los reportes incluyen análisis de frecuencia
6. Las búsquedas son case-insensitive
7. Los puertos, barcos y capitanes se pueden listar
8. Se pueden hacer backups en cualquier momento
9. La optimización libera espacio en disco
10. Los logs contienen toda la información de depuración
