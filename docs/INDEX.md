### Menu Options / Opciones de Menú / Επιλογές Μενού

All documentation files contain detailed explanations of each menu option:

1. **Concatenate OCR text files by date** - Concatenar archivos OCR por fecha - Συνένωση αρχείων OCR ανά ημερομηνία
2. **Extract TRAVERSING ENTRANCES** - Extraer entradas de travesía - Εξαγωγή καταχωρήσεων διαδρομής
3. **Extract CABOTAGE ENTRIES** - Extraer entradas de cabotaje - Εξαγωγή καταχωρήσεων καμποταζ
4. **Extract by YEAR (with threads)** - Extraer por AÑO (con hilos) - Εξαγωγή ανά ΕΤΟ (με νήματα)
5. **Reprocess YEAR** - Reprocesar AÑO - Επανεπεξεργασία ΕΤΟ
6. **Check missing files** - Verificar archivos faltantes - Έλεγχος αρχείων που λείπουν
7. **Show database statistics** - Mostrar estadísticas de BD - Εμφάνιση στατιστικών BD
8. **Export all years** - Exportar todos los años - Εξαγωγή όλων των ετών

### Data Structure / Estructura de Datos / Δομή Δεδομένων

- Cabotage Entry (Domestic Arrivals) - Entrada de Cabotaje (Llegadas Domésticas) - Καταχώρηση Καμποταζ (Εγχώριες Αφίξεις)
